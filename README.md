# ⚖️ Calculadora de IMC

Uma aplicação simples em JavaScript que calcula o Índice de Massa Corporal (IMC) com base no peso e altura informados pelo usuário, exibindo também a classificação correspondente.

---

## 🌐 Acesse o projeto <a id="acessar-projeto"></a>

👉 https://lucasoeditor.github.io/calculadora-IMC/

[![Abrir no navegador](https://img.shields.io/badge/Acessar-Projeto-green)](https://lucasoeditor.github.io/calculadora-IMC/)

---

## 🚀 Funcionalidades

* Inserção de peso e altura
* Cálculo automático do IMC
* Exibição do resultado
* Classificação do IMC (ex: abaixo do peso, normal, sobrepeso, etc.)
* Validação de entrada inválida

---

## 💡 Lógica básica

* O usuário informa seu peso (kg) e altura (m)
* O sistema calcula o IMC utilizando a fórmula: peso ÷ (altura × altura)
* Com base no resultado, o sistema retorna a classificação correspondente
